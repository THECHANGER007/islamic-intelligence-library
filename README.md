# Islamic Intelligence — library

The library of the Islamic Intelligence app (free, non-commercial). The app downloads it by itself on its first
start; it is a SQLite file cut into parts.

Sources and terms (details: docs/DATA_SOURCE_REGISTRY.md in the app's project):
- Qur'an text: Tanzil Project — https://tanzil.net (verbatim copy, credit and link required).
- Tafsir and i'rab: Quranpedia.net (الموسوعة القرآنية) dump 2026-10-30 — https://quranpedia.net/dumps
- Hadith: the nine books as in the project's hadith source (grades as given by the graders named in the app).
- The 37 madhhab, creed and sharh books: OpenITI (KITAB project) — https://github.com/OpenITI —
  CC BY-NC-SA 4.0: this library, as derived from them, is shared under the same licence, non-commercial.
- Bible: Van Dyck (Arabic), King James Version, JPS 1917 — public domain.
- Bhagavad Gita: Shri Purohit Swami (1935) via github.com/gita/gita; Dhammapada: Bhikkhu Sujato, SuttaCentral (CC0).
Search indexes, normalized text and page numbers are the app's own processing; the words of the texts are unchanged.
